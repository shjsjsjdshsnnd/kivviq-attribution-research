# Step 3.11 Baseline Validation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and freeze a public, evaluator-owned validation library that produces reproducible machine-readable conformance reports for all 27 frozen baseline operators.

**Architecture:** `src/validation/` consumes canonical operator and evaluator evidence but never widens the operator input boundary. Focused validators produce immutable PASS/FAIL check results; the harness aggregates every required check into a stable report whose fingerprints are independently recomputed. Tests own executable worlds and operator-specific assertions while importing all validation semantics from the public `./validation` package subpath.

**Tech Stack:** TypeScript 5.9, Vitest 3.2, dependency-cruiser, existing Step 2 Action Ontology, Step 3.1 evaluation contracts, and Step 3.10 canonical operator interface.

---
